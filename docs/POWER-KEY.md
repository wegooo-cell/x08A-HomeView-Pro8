# 电源键与双桌面切换

**需要固件已经把短按电源键映射为 HOME。安装器不会改写系统按键文件，也不会自动取得 root。** 未做此映射的普通 POWER 键仍按固件原有方式工作。

满足这个前提并把 HomeView 设为默认桌面后：

- 正在 HomeView 主界面：短按一次返回 Pro8 原生桌面。
- 正在原生桌面或其他应用：短按一次回到 HomeView。
- 刚亮屏的 650 毫秒内不触发反向切换，避免唤醒立即跳走；连续切换有 350 毫秒保护。
- 程序内部的“返回 HomeView”使用明确标记，不触发切回原生桌面。

长按电源键仍由固件处理，不等同于上述短按行为。若启用双击 HOME 休眠，需按设备提示授予普通锁屏管理权限；未授权时不能强制锁屏。

这是应用响应 HOME 后的双桌面逻辑，相关源码为 `DesktopSwitchPolicy.java`、`HomeKeyController.java` 与 `HomeActivity.java`。它与原始 POWER 扫描码的固件映射是两个步骤。仓库不提供获取系统权限或刷写按键布局的步骤。

不需要双桌面切换时，可以在 Android 默认桌面设置中选择系统桌面。无需卸载 HomeView、删除照片或退出账号。
