# 数据与权限

安装器只连接用户选定且已授权 USB 调试的设备。电脑端页面绑定 127.0.0.1 随机端口，使用本次运行的随机访问令牌，修改请求检查来源。配置入口要求调用方具备 Android DUMP 权限；该限制保护入口，并没有向 HomeView 授予 DUMP 权限。安装器不使用 root、Device Owner 或无线调试。

配置内容限于天气城市、家庭来源与名称、HA 地址、待机方式与等待时间、默认桌面、输入法选择、电源键配置和用户主动导入的图片。不接受账号凭据。应用升级保留原有数据，不自动卸载、清数据或降级。

城市搜索优先访问 UAPI，兼容查询可能访问 Open-Meteo。天气数据默认访问 UAPI，失败时访问万象数据 API；仅发送所选城市名称、行政区划代码等查询参数，不发送账号凭据，不使用 IP 自动定位。天气缓存保存在 Pro8 的 HomeView 应用私有存储；应用与源码包从 GitHub Release 获取；ADB 来自 Google；小企鹅可选下载来自其官方 GitHub Release。这些服务会按各自政策处理请求。安装器不把你的 HA 地址、图片或配置上传 GitHub。

图片先保存在本机临时目录，关闭安装器时清理副本；电脑原图保留。通过 USB 写入设备 Pictures/HomeView，并在应用私有目录生成预览。设备相册删除功能会在确认后删除原图。应用存储权限用于读取、同步和删除这个目录。

音乐、HA、iCloud 等账号由设备端登录，凭据保存在应用私有目录。米家沿用系统内置应用与其已有登录。公开源码、APK、安装器与配图不包含维护者账号、私人相册、家庭清单或签名私钥。

默认桌面、可选输入法选择仅在用户勾选后通过标准 ADB 命令应用。悬浮窗、设备管理等应用内可选功能应按 Android 界面说明单独授权；电脑安装器不自动开启这些权限。系统应用、文件管理等入口用于调用设备现有应用。

视频封面兼容组件仅在检测到 `dev.pro8.bili` 时安装。它通过原有签名权限读取固定的视频元数据接口，只接受已核对包名与证书的 HomeView 调用，只返回视频标题、标识、更新时间和封面，不转发账号凭据，不允许写入。两个应用原有账号与数据保持。

安装器默认通过 Android InputManager 为 Pro8 PMIC 背部按键选择布局覆盖，仅改变扫描码 116；使用 ADB shell 已有权限，不向 HomeView 授予键盘布局权限。电脑保存原布局选择的恢复记录。双击熄屏需要用户在设备系统窗口确认普通设备管理的 force-lock 权限，安装器不自动点击或强制激活。

授权按钮被 Pro8 透明手势浮层遮挡时，安装器仅在授权期间临时隐藏 `com.android.systemui` 的 `SYSTEM_ALERT_WINDOW` 浮层；先记录原模式，结束立即恢复，并在设备端设置 150 秒恢复保护，电脑退出或 USB 断开也能恢复。不改变 SystemUI 的启用状态，不代替用户确认锁屏授权。
