# 公开版与维护者本地部署的范围

| 项目 | v0.1.4 公开部署 |
| --- | --- |
| 桌面、图标与天气组件布局 | 发行安装包沿用本地版布局、间距与显示效果；仓库画面预览保持现有示意图 |
| 锁屏与表盘 | 本地版现有 10 款默认加入图库；数字与场景的自定义入口保留。尊重已有用户手动移除的选择 |
| 内置米家 | 本机服务桥接，已修复开关状态参数；两个控制位可任选可开关设备 |
| Home Assistant | 连接用户已有服务，设备端授权；两个控制位支持灯、开关、空调、风扇、加湿器及辅助开关 |
| 音乐与相册 | 设备端扫码、红心与评论窗口；公共相册文件夹与删除入口；依赖账号和服务实际可用性 |
| 小企鹅 | 可选官方 APK + Pro8 主题文件；首次在设备选择主题 |
| 系统优化 | 默认停用系统应用商店与系统更新组件，并限制这两个组件后台；保存恢复记录 |
| 物理电源键切换 | 应用逻辑已公开，但依赖固件已有 POWER→HOME 映射；安装器不改系统按键文件 |
| 第三方应用 | 哔哩哔哩、独立音乐、投屏/车载等其他客户端需用户自行安装；不会复刻维护者设备的整套应用清单 |
| 哔哩哔哩封面组件 | 检测到兼容视频组件时安装只读签名桥，恢复推荐标题与模糊封面；保留原视频账号 |
| 哔哩哔哩壁纸入口 | 安装自有小型兼容入口，允许旧客户端调用公开版相册；不分发第三方视频客户端 |
| 维护者以前的应用精简 | 不复用针对个人设备的第三方卸载清单；公开优化仅上述两个固定系统组件 |
| 账号、天气城市、家庭、照片 | 账号自行登录；城市和地址可在电脑选；只导入用户明确选中的图片，保留原有数据 |

安装器不会恢复维护者的账号、家庭设备、ADB 授权、照片、私有主题设置或固件修改。设备端首次体验仍是新用户自己的登录与配置。

源码包含可再分发的默认素材，素材与代码遵循各自许可。未在仓库提供的独立资源不作为开源素材展示；具体构建入口见 [构建说明](BUILDING.md)。
