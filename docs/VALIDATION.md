# v0.1.1 验证范围

- 共享安装器：26 项 Python 检查通过，覆盖配置白名单、设备解析、输入法保留、签名/版本校验、图片导入、本地接口授权，以及优化备份/恢复。
- 自动识别：隔离浏览器验证启动即扫描、授权后自动更新、刷新保留会话、多设备保留选择、部署期间暂停轮询，以及默认优化参数。
- 家庭组件：隔离浏览器验证两个插座、两个灯、风扇与加湿器三组配置。两个位置均可选所有支持的控制域，温度传感器不会混入开关列表。
- 表盘：核对本地 v168 目录，现有 10 款首次默认启用，旧版原样保存的七款默认配置会一次性升级为十款，其他自定义启用组合保留，升级后仍可移除；信息锁屏不恢复。
- Android：SDK 28 / JDK 17 编译，校验 APK 包名、版本、签名、SHA256。逐个核对 289 个前端文件按当前源码与外部资源组合打包，实际安装所需字体、图标、天气与表盘资源单独比对。
- Pro8 真机：内置米家在线灯具完成开关并验证状态变化，随后恢复原始开关状态。此测试不代表所有设备型号或全部调节能力均已验证。
- Pro8 相册兼容：临时普通 UID 应用通过旧包名入口调用公开版相册，成功取得用户选择的图片结果与临时读取权限；不更改壁纸，临时应用已删除。
- Pro8 更新：覆盖更新保留 26 张照片及各文件 SHA256，保留默认输入法和默认桌面，无账号清理。
- 发布检查：无维护者账号、私钥、私人地址或设备备份；独立外观资源未提交为开源素材。GitHub 现有 5 张预览图逐字节未变。
- 三平台安装器：由同 tag 的 GitHub Actions 在 Windows x64、Mac arm64、Mac x64 构建，执行 Python 检查和打包资源自检；工作流成功后才公开新版下载。

电脑端资源自检不等于在每台 Windows/Mac 上完成 USB 真机安装。固件、驱动、网络、服务账号及第三方应用仍影响实际可用能力。

# v0.1.0 验证范围

- 共享安装器：21 项 Python 自动检查，覆盖保留输入法、版本与签名冲突、配置字段白名单、图片格式/尺寸、本机 Host/Origin/访问令牌、上传和删除临时副本。
- 电脑配置界面：8 项隔离浏览器检查，覆盖城市、家庭名称、待机、多选文件入口、图片预览/壁纸选择、设备选择、提交参数和完成状态。
- 桌面、设置、家庭来源和壁纸页面：隔离渲染检查无 JavaScript 错误、无缺失资源；公开配图使用示意数据。
- Android：SDK 28 编译、APK 包名/版本/证书/SHA256 验证；逐个比对打包 frame 文件与公开源文件一致。
- Pro8 / X08A 真机：使用本地已校验发行 APK，运行完整共享部署引擎首次安装，验证天气、家庭名称与 HA 地址、待机配置、照片传入和设为桌面壁纸。默认输入法和默认桌面不变，原有 26 张照片保留。测试后移除独立测试包及测试图片，返回个人版。
- 电脑打包：本地 Mac arm64 已完成可执行文件资源自检；公开 Release 的 Windows x64、Mac arm64、Mac x64 由 GitHub Actions 分别构建，执行同一套 Python 检查和打包后资源自检。具体状态可查看对应 tag 的 `Desktop installers` 工作流。

电脑端资源自检不等同于在每一台 Mac/Windows 上完成 USB 真机安装。当前 USB 配置逻辑已在上述 Pro8 上验证；不同固件、驱动、网络、第三方服务和用户账号仍可能影响结果。未在此发行版重新验证所有音乐账号权限、全部米家设备类型或外部视频客户端的功能。
