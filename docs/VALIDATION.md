# v0.1.0 验证范围

- 共享安装器：21 项 Python 自动检查，覆盖保留输入法、版本与签名冲突、配置字段白名单、图片格式/尺寸、本机 Host/Origin/访问令牌、上传和删除临时副本。
- 电脑配置界面：8 项隔离浏览器检查，覆盖城市、家庭名称、待机、多选文件入口、图片预览/壁纸选择、设备选择、提交参数和完成状态。
- 桌面、设置、家庭来源和壁纸页面：隔离渲染检查无 JavaScript 错误、无缺失资源；公开配图使用示意数据。
- Android：SDK 28 编译、APK 包名/版本/证书/SHA256 验证；逐个比对打包 frame 文件与公开源文件一致。
- Pro8 / X08A 真机：使用本地已校验发行 APK，运行完整共享部署引擎首次安装，验证天气、家庭名称与 HA 地址、待机配置、照片传入和设为桌面壁纸。默认输入法和默认桌面不变，原有 26 张照片保留。测试后移除独立测试包及测试图片，返回个人版。
- 电脑打包：本地 Mac arm64 已完成可执行文件资源自检；公开 Release 的 Windows x64、Mac arm64、Mac x64 由 GitHub Actions 分别构建，执行同一套 Python 检查和打包后资源自检。具体状态可查看对应 tag 的 `Desktop installers` 工作流。

电脑端资源自检不等同于在每一台 Mac/Windows 上完成 USB 真机安装。当前 USB 配置逻辑已在上述 Pro8 上验证；不同固件、驱动、网络、第三方服务和用户账号仍可能影响结果。未在此发行版重新验证所有音乐账号权限、全部米家设备类型或外部视频客户端的功能。
