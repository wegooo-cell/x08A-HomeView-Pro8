# 源码默认素材

- `wallpaper-blue.png`：维护者选定的沙丘默认壁纸，来源与 SHA256 见根目录 WALLPAPER.json；其模糊纹理仅用于卡片。
- 应用图标、天空与其他位图：源码构建使用公开默认图形，相关可编辑 SVG 保存在 tools/appearance-source。它们不包含用户账号、原应用图标提取文件或个人封面。
- `ion-*.svg`：Ionicons 7.4.0，MIT，保留 ionicons-LICENSE.txt。
- `weather-*.svg` 与 `bs-*.svg`：Bootstrap Icons，MIT，声明在同目录。
- 当前歌曲封面和第三方组件画面由设备上的账号与服务提供，不属于内置默认素材。

独立外观归档的可选构建入口见 docs/BUILDING.md；该归档不作为源码素材提交。
