# Calendar UI icons

Ionicons 7.4.0, MIT: https://github.com/ionic-team/ionicons/tree/v7.4.0/src/svg . Nine new outline/action icons were downloaded from the pinned https://cdn.jsdelivr.net/npm/ionicons@7.4.0/dist/svg/ endpoint. Add, close, checkmark, chevron-up and home-outline reuse the existing desktop Ionicons files. License included.

Icons replace the closest matching Apple toolbar/control symbols; SF Symbols and Apple font files were not copied. The calendar is editable HTML/CSS UI, not a screenshot pasted as the app. Official screenshots are visual references in the design project's references/ipad-calendar-official/ only.
